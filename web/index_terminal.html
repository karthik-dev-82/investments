NIFTY Index Terminal

Daily levels of three NSE Total Return Indices (TRI: dividends reinvested, the fair benchmark for a Growth-option fund), plus five Balanced Advantage funds (Direct, Growth) as comparison series — switch them on in the legend. Scroll to zoom, drag to pan — switch tabs for drawdowns, calendar-year returns, rolling returns and volatility. What do these mean? See the notes.

Drawdown = % below the running all-time-high close. Rolling return = annualized return over the trailing N years, recomputed for every trading day. Volatility = annualized standard deviation of daily log returns over the trailing window (×√252 trading days/year).
